🍿 Лучший бот для киномана

Привет, киноман! Этот бот создан, чтобы ты никогда не забыл, что смотрел вчера, и знал, что смотреть завтра.

🎲 Особенности:
• Умные рекомендации на основе твоих вкусов
• Детальная статистика (любимый актер, жанр, год)
• Удобное ведение списка просмотренного

👤 Автор: @Inf0voz
📦 Версия: Beta 0.1
