## 🚀 Возможности

| | | |
|---|---|---|
| 🔍 | **Поиск фильмов** | По названию через The Movie Database |
| ➕ | **Добавление** | С постером, рейтингом, жанрами, режиссёром и актёрами |
| 📋 | **Список** | Все сохранённые фильмы с рейтингами |
| 🗑 | **Удаление** | Пошаговое удаление с подтверждением |
| 📊 | **Статистика** | Любимые жанры, режиссёры, актёры, средний рейтинг |
| 🎲 | **Рекомендации** | Подборки на основе твоих предпочтений |

---

## 🧠 Рекомендации

Бот анализирует список по трём критериям:

- 🎭 **Жанры** — чем чаще смотришь, тем весомее
- 🎥 **Режиссёры** — самый сильный критерий (×3)
- 👤 **Актёры** — любимые актёры дают точные подборки (×2)

Топ-3 фильмов по сумме баллов попадают в рекомендации. Есть кнопка «Ещё» для обновления подборки.
